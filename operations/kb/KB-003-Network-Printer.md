# KB-003 — Imprimante réseau

## Symptôme
L'imprimante est hors ligne.

## Causes
1. Imprimante éteinte
2. Câble débranché
3. Mauvaise adresse IP

## Solution — Étapes

1. Vérifier physique (allumée, câble branché)
2. Vérifier IP de l'imprimante
3. Tester `ping <IP imprimante>`
4. Dans Windows → Périphériques et imprimantes
5. Vérifier le port correspond à l'IP
6. Réinstaller l'imprimante si besoin

## Validation
- Une page de test s'imprime
- L'imprimante est "En ligne"

## Catégorie
Périphérique / Imprimante
